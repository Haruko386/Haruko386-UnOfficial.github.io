# 世界建筑地图

这个目录是 `world/` 之外的兴趣点展示层。uNmINeD 重新生成后，可以直接用新的
`world/` 覆盖旧目录；这里的兴趣点资料和截图不会受影响。

## 添加或修改兴趣点

在仓库根目录用 PowerShell 运行：

```powershell
.\tools\start-poi-editor.ps1
```

编辑器会自动在浏览器中打开。点击“新建”，再点击地图上的建筑位置，填写介绍并上传
截图，最后点击“保存修改”。截图会在浏览器中自动缩放到最长边不超过 1920 像素，并
转换为 WebP，以减少仓库和页面流量。保存结果是 `map/pois.json` 和 `map/media/` 中的普通静态
文件，把它们和网站一起提交即可。

GitHub Pages 上没有保存接口，因此线上页面只能查看，无法修改数据。

兴趣点可以分别选择标记颜色。地图刚打开的概览缩放档会按空间距离自动去重：密集区域
优先保留介绍文字量较多的代表点，离群或独立区域的兴趣点仍然显示，不限制全图总数。
向内放大一档后显示全部兴趣点。编辑器中的兴趣点清单在数量较多时默认收起，也可以
随时用“展开/收起”按钮切换。

## 更新世界地图

1. 用 uNmINeD 生成新的完整 `world/` 文件夹。
2. 用它直接覆盖仓库中的 `world/`。
3. 本地启动兴趣点编辑器，确认旧兴趣点仍落在正确位置。
4. 提交 `world/` 的更新。

查看页面入口是 `/map/`。兴趣点永久链接采用 `/map/?poi=兴趣点ID`。
